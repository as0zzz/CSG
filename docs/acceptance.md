# Проверка демонстрационного прототипа

Проверка выполнена локально 12 ноября 2026 года. Backend: Python 3.12 в Docker, реальная PostgreSQL/PostGIS и приватный MinIO. Серверные тесты используют отдельную базу `aksg_test_<uuid>`; основная база не очищается.

## Автоматические проверки

- `python -m app.test_runner`: **15 тестов пройдено**, 44,09 с в первом полном запуске и 22,76 с при повторной проверке финального образа с requirements.lock. Наблюдались предупреждения сторонних библиотек о будущих изменениях API; ошибок тестов нет.
- Frontend: TypeScript и production-сборка Vite пройдены; ESLint пройден.
- Проверка production-зависимостей npm: 0 уязвимостей. Полный npm audit на момент проверки показывает 7 moderate в транзитивной dev-зависимости minimatch, используемой TypeScript ESLint. В итоговый nginx-образ эти пакеты не включаются. Автоматическое понижение версий и принудительная замена major зависимостей не применялись.

## Проверка браузером

Использовался встроенный Chromium-браузер, разрешения 1440×900 и 1024×768. Выполнен сценарий Planner → RemoteInspector → Planner → CustomerViewer:

1. Через UI создана работа `ДЕМО-013` «Контрольный участок водоотвода», план 100 м, диапазон ПК 100+00 — ПК 104+00.
2. Инспектор сохранил подтверждение 40 м со связанным изображением. В КСГ осталось 0 / 100 м, статус «Запланирована», кнопка создания работы инспектору недоступна.
3. Планировщик отдельно принял 40 м с причиной. В КСГ стало 40 / 100 м, статус не изменился автоматически.
4. Заказчик открыл карточку с 40% готовности, исходной проверкой, доказательством и журналом объёмов. Кнопки редактирования отсутствуют.
5. Синтетический MP4 загрузился в браузере с duration=6 и readyState=4; после нажатия Play paused=false, currentTime вырос.
6. Через файловый диалог загружен синтетический `qa-upload.png`; карточка и изображение появились в разделе материалов.
7. Администратор запустил симулятор и перевёл его в состояние «Нет сигнала». Интерфейс показал новую точку и время, источник simulated.
8. Через UI создан отдельный проект `ДЕМО-QA`, добавлен существующий планировщик, ось и подрядчик. Это явно обозначенные дополнительные тестовые данные; они не подменяют изолированный проект seed.

Основные экраны и формы просмотрены в двух разрешениях. Широкие таблицы имеют внутреннюю прокрутку, диалоги ограничены высотой экрана. В процессе исправлены очистка необязательного текста и сброс введённого диапазона при смене работы.

Финальная проверка выполнена на штатном Compose без dev-mount. `scripts/check-persistence.py` сравнил 13 работ, 7 проверок, количество записей аудита и SHA-256 шести объектов до и после обычного restart, затем после пересоздания API/web из финальных образов. Обе проверки пройдены. Анонимный запрос к bucket MinIO получил HTTP 403. Исправления очистки необязательного текста и закрытия модального окна Escape дополнительно проверены через UI.

Ограничения оценки: проверки относятся к локальному демонстрационному набору и указанным сценариям. Нагрузочное тестирование, реальные устройства и промышленная эксплуатация в приёмку варианта 1 не входят.
