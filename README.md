# КСГ — диаграмма Ганта и чёрный ящик

Текущий этап проекта: простой контрольно-сетевой график с записью поведения пользователя для последующей подготовки обучающих данных. Главный экран — таблица работ и календарная диаграмма Ганта. Дополнительно доступны сетевая схема и журнал записи действий.

## Открыть приложение

http://localhost:8080

Демо-пользователь: `planner@demo.local`. Пароль — значение `DEMO_PASSWORD` в локальном `.env`; скрипт настройки создаёт его случайным. Файл `.env` не хранится в Git.

## Что работает

- Работа: название, код, дата начала, длительность и предшественники.
- Перенос полосы мышью; растягивание края изменяет длительность.
- Стрелки на клавиатуре сдвигают выбранную полосу на день, Enter открывает карточку.
- Создание графика, добавление и архивирование работ, связывание работ, отмена последнего изменения работы.
- Зависимости «окончание → начало», запрет циклов и конфликтов версий.
- Явная команда расчёта сроков по зависимостям; ручной перенос не запускает скрытый пересчёт остальных работ.
- Критический путь и сетевое представление; поиск, масштаб и прокрутка календаря.
- Чёрный ящик: события интерфейса, жесты, контекст, серверные снимки графика до/после и JSONL-выгрузка.

По умолчанию открывается график строительства железнодорожного пути на участке ПК 100–120: 15 строительных работ с числовой нумерацией, датами и технологическими зависимостями. Геодезия, подготовка площадки, земляное полотно, водоотвод, геотекстиль, защитный слой, балластировка, укладка пути, сварка, СЦБ, контроль и приёмка. Длительности демонстрационные. Старые проекты и их данные сохранены; учебный буквенный пример скрыт из рабочего интерфейса.

## Запись поведения

Запись включается после входа внутри выбранного графика. Зелёный индикатор показывает состояние записи; неприсланные события отображаются как очередь. Вкладка «Чёрный ящик» позволяет выбрать сессию, проверить события и скачать JSONL.

События сначала сохраняются в IndexedDB браузера и удаляются из очереди после подтверждения сервера. Повторная доставка имеет идемпотентные идентификаторы. Серверные изменения и их снимки записываются в той же транзакции, что и изменение графика. Пароли и действия вне КСГ не записываются.

Для тестов используется URL `http://localhost:8080/?recording=test`: такие сессии имеют отдельную метку и не смешиваются с пользовательскими. Данные для обучения требуют последующего отбора и подготовки. Модель сейчас не обучается.

Формат выгрузки и ограничения: [docs/blackbox.md](docs/blackbox.md).

## Запуск и проверка

Требуется Docker Desktop с Linux containers. Из папки проекта:

```powershell
.\scripts\init-env.ps1
docker compose up -d --build
docker compose ps
```

Миграции и идемпотентные демоданные применяются автоматически. Данные PostgreSQL и MinIO сохраняются в именованных volumes. Для остановки без удаления данных:

```powershell
docker compose stop
```

Проверки:

```powershell
docker compose exec api python -m app.test_runner
cd frontend
npm ci
npm run build
npm run lint
node --experimental-strip-types --test tests/schedule.test.mjs
```

Выполнены 21 серверный тест и 5 тестов календарного расчёта. В браузере проверены перенос, изменение длительности, отмена, сетевая схема, появление событий и скачивание JSONL. Проверка искусственного разрыва связи в браузере отдельно не проводилась.

## Код

- `frontend/src/Planner.tsx`, `planner.css` — новый рабочий интерфейс.
- `frontend/src/schedule.ts` — календарный расчёт и критический путь.
- `frontend/src/recorder.ts` — запись и локальная очередь доставки.
- `backend/app/planner.py` — API планирования, запись и выгрузка сессий.
- `backend/app/models.py` — работы, связи, сессии и события.
- `backend/alembic/versions/002_blackbox.py` — миграция чёрного ящика.
- `backend/app/plan_seed.py` — строительный график ПК 100–120, без перезаписи существующих работ.

Предыдущая расширенная версия интерфейса сохранена в `frontend/legacy`; её описание — `docs/legacy-prototype-readme.md`. Приоритет текущего этапа — КСГ и запись действий. Камеры, инспектирование и обучение модели не входят в текущий пользовательский интерфейс.
